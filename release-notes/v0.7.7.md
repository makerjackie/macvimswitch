# MacVimSwitch v0.7.7

这个版本修复了切回中文输入法后，第一个字母偶尔仍由 ABC 输入的问题。

## 修复与改进

- 修复按 Shift 从 ABC 切回豆包等 CJKV 输入法后，首字母有概率直接输入英文的问题。
- 切换期间会暂存键盘事件，确认目标输入法稳定后再按原顺序回放；现在可以在按完 Shift 后立即继续打字，不需要人为等待。
- 改用主线程上的非阻塞状态检查，等待输入法就绪时不会卡住键盘事件监听。
- 菜单栏在切换期间会短暂显示“正在切换”图标，并提示可以继续输入。
- 增加立即输入和连续快速输入测试，覆盖 Shift 松开后 0ms 输入首字母及连续输入 `nihao` 的场景。

## 更新与安装

- v0.7.6 会在启动时自动检查一次更新，之后每 24 小时检查一次；也可以从菜单栏选择“检查更新”。
- 更新弹窗的“下载”按钮会打开固定的最新版 `MacVimSwitch.dmg`。
- Bundle ID 继续保持为 `com.jackiexiao.macvimswitch`，并继续使用同一个 Apple Developer Team 的 Developer ID Application 证书签名和 Apple 公证。
- 从 v0.7.6 升级时，正常情况下不需要重新授予辅助功能权限。

发布包同时支持 Apple Silicon 和 Intel Mac。
