# MacVimSwitch v0.7.6

这是一个以可靠性、正式签名和更新体验为重点的版本。

## 修复与改进

- 修复切回中文/CJKV 输入法后，菜单栏显示正确但实际仍输入英文的问题。
- 改用 macOS 原生“选择上一个输入源”快捷键恢复完整文本输入会话，并修复快捷键松开事件缺少 Fn 等修饰键的问题。
- 增加输入源稳定确认、失败重试和事件监听自动恢复。
- 豆包输入法实测 100 次连续 ESC/Shift 循环全部通过；Shift → 豆包端到端中位延迟约 138ms。
- 修复更新检查偶尔失败：不再使用容易触发匿名限流的 GitHub REST API，改用 GitHub 官方 latest-release 重定向。
- “下载”按钮现在直接打开最新版 `MacVimSwitch.dmg`。

## 签名与安装

- Bundle ID 保持为 `com.jackiexiao.macvimswitch`。
- 从本版本开始，发布包使用同一 Apple Developer Team 的 Developer ID Application 证书签名，并经过 Apple 公证。
- 从 v0.7.6 升级到后续正式签名版本时，不应再反复请求辅助功能授权。
- 由于 v0.7.5 及更早版本使用 ad-hoc 签名，首次从旧版迁移到 v0.7.6 时，macOS 仍可能要求重新授权一次；这是签名身份迁移所必需的最后一次操作。

## 使用前确认

- 请关闭输入法自身的“使用 Shift 切换中英文”，避免它与 MacVimSwitch 同时处理 Shift。
- 请在“系统设置 → 键盘 → 键盘快捷键 → 输入法”中启用“选择上一个输入源”。

发布包同时支持 Apple Silicon 和 Intel Mac。
